# Resume Screening NLP Tool

Fine-tuned BERT classifier to match resumes with job descriptions.
- Achieved 89% top-3 match accuracy.
- Interactive Streamlit demo for testing resumes.

## Setup
conda activate D:/conda_envs/resume_nlp
pip install -r app/requirements.txt

## Run
streamlit run app.py
